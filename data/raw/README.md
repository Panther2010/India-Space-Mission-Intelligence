# Raw data

Downloads land here exactly as received and are never edited. Cleaning happens in notebooks, which write to `data/processed/`.

| Folder | Contents | Committed to git? |
|---|---|---|
| `firms/` | VIIRS fire detections, one CSV per 10-day block and source | No (size) |
| `boundaries/` | geoBoundaries GeoJSON and metadata | No (ODbL share-alike; fetched by script instead) |
| `sentinel2/` | Sentinel-2 extracts (Week 2) | No (size) |
| `research/` | Hand-compiled datasets A (ecosystem) and B (missions) | Yes |
