# Dashboard (Streamlit, Week 3)

The app will be deployed on Streamlit Community Cloud from this repository. It reads small precomputed files from `data/processed/`; nothing heavy is computed live.

| Page | What it shows |
|---|---|
| Mission Explorer | Filter satellites by operator, sensor, orbit, application and status (dataset B) |
| Indian Startup Landscape | A map and table of companies by value-chain role and capability (dataset A) |
| EO Analysis | The burnt-area map with first-seen dates, VIIRS points, the missed share and how it changed since 2021, the classifier's results and the forecast against actuals |
| Mission Trade-offs | Data options compared on the customer's requirement, with the recommendation |
| Commercial Opportunity | User, pain point, solution, value proposition, risks and the next validation step |
